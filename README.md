# *Calculadora Colaborativa — Git y GitHub*

## Descripción
Repositorio de práctica realizado en equipo para aprender el uso de Forks y Pull Requests en GitHub.

El proyecto consiste en una calculadora básica desarrollada en Python, utilizada como ejercicio colaborativo para practicar contribuciones entre distintos integrantes del equipo.

## Contenido
- calculadora.py — Aplicación de calculadora básica con menú interactivo
- README.md — Documentación principal del proyecto

## Funcionalidades
La aplicación permite:

- Mostrar un menú interactivo.
- Realizar sumas entre dos números.
- Realizar resta entre dos números.
- Realizar multiplicaciones entre dos numeros.
- Salir del programa desde consola.

## Cómo ejecutar

*Requisito: tener Python 3 instalado.*

### En Windows
bash
python calculadora.py


o también:

```bash
python calculadora.py
```


### En Linux o MacOS
bash
python3 calculadora.py


## Objetivos del ejercicio
- Aprender a trabajar con Forks en GitHub
- Practicar Pull Requests
- Simular contribuciones colaborativas
- Utilizar Git en equipo
- Resolver integraciones de cambios
